Dashcam-Based Evidence Verification System

Architecture & Tech Stack — for insurance-fraud and incident-verification use cases (accident / theft / robbery)

1. System Overview

Two roles: User (private vehicle owner with dashcam) and Officer (police / insurance investigator). When an incident is reported, the Officer queries by location + time window, discovers nearby dashcam-equipped vehicles via stored GPS trip metadata, and emails those owners a footage request. On consent, the backend auto-trims the exact time segment and uploads it as locked, hashed evidence — never accessed without the owner's explicit agreement.

    G-->>B: List of matching device IDs

    U-->>B: Taps "Agree"
    B->>U: Pull raw clip for that window only
    U-->>F: Upload raw segment
    F->>F: Trim to exact [t_from, t_to]
    F->>F: Compute SHA-256 hash
    F->>L: Append {hash, timestamp, request_id} (chained to prior hash)
    F->>S: Store trimmed clip, set locked_until = now + 30 days
    S-->>O: Evidence available for review

6. Evidence Integrity Design

Hash-and-timestamp on first contact: the moment a request is generated, the system logs a fact record — device, location, time window, request time — before any video is uploaded. If a clip is later submitted, its SHA-256 hash is compared; a mismatch or a missing submission after a logged request is itself evidence.

Append-only, hash-chained ledger: each ledger entry's hash is computed from its own data plus the previous entry's hash (hash_N = SHA256(data_N + hash_(N-1))), so tampering with any past record breaks every hash after it — detectable without needing real blockchain infrastructure.

DB-enforced lock: uploaded evidence is locked via a locked_until timestamp and a Postgres trigger that rejects DELETE/UPDATE until that time passes; the application's DB role is also stripped of DELETE privileges as a second line of defense.

Scope note: this design never accesses or copies footage without the owner's explicit consent, and the lock/ledger only applies to footage the user has already agreed to share — keeping the whole system on the right side of privacy and evidence-handling norms.
